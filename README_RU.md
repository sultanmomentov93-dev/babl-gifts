# Бабл Gifts — стартовый проект

Стартовый каркас Telegram Mini App: интерфейс, сервер FastAPI, SQLite, ежедневный бонус и коллекция виртуальных предметов.

## Что уже есть
- Главный экран с героем Баблом
- Баланс игровых монет
- Ежедневный бонус с серверной проверкой
- Открытие виртуальной коробки за монеты
- Инвентарь и таблицы SQLite
- Проверка Telegram Mini App `initData` на сервере (когда задан BOT_TOKEN)
- Локальный режим для тестирования в браузере

## Пока не включено
- Реальная оплата Telegram Stars
- Автоматическая отправка настоящих Telegram-подарков
- Реферальные награды и рейтинг

Эти функции нельзя безопасно имитировать одной кнопкой: оплату нужно подтверждать через Telegram, а реальную выдачу подарков — выполнять отдельной серверной операцией с проверкой доступности метода/подарка.

## Запуск на Android через Termux
1. Установи Python и Git в Termux.
2. Распакуй архив в папку проекта.
3. Перейди в папку проекта:
   `cd babl_gifts_starter`
4. Создай виртуальное окружение (по желанию):
   `python -m venv .venv`
   `source .venv/bin/activate`
5. Установи зависимости:
   `pip install -r requirements.txt`
6. Для локального теста:
   `python -m uvicorn server:app --host 0.0.0.0 --port 8000`
7. Открой в браузере `http://127.0.0.1:8000`.

## Для Telegram
- Создай бота через @BotFather и сохрани токен в переменную окружения `BOT_TOKEN`.
- Опубликуй проект на хостинге с HTTPS, например Render.
- Укажи URL сайта как `WEBAPP_URL` в настройках бота/деплоя.
- Для настоящей авторизации Mini App открывай приложение кнопкой Web App из Telegram.
- Не публикуй токен в GitHub и не вставляй его в HTML.

## Переменные окружения
- `BOT_TOKEN` — токен Telegram-бота (необязателен для локального демо)
- `DATABASE_PATH` — путь к SQLite, по умолчанию `babl_gifts.db`
- `ALLOW_DEMO_AUTH` — `true` разрешает тестовый профиль только для локальной демонстрации; на публичном деплое выставить `false`.

## Важно
Для production нужно отключить демо-авторизацию и настроить BOT_TOKEN. До этого не принимай реальные платежи и не обещай выдачу реальных подарков.
